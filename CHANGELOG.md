# Changelog

## [0.1.0] - 2026-11-27

### Added

- Alt-click folder palettes in the Project tree, content list and thumbnails.
- Native folder icon colors, corner badges, tree row colors and inherited tree regions.
- HierarchyDecorator-style selection blending and optional alternating tree row backgrounds.
- Personal asset and folder favorites with search, drag and drop, ordering and scene-opening save prompts.
- General and Visual preferences with automatic language selection and five supported languages.
- Independent Editor-only installation through UPM, VPM or UnityPackage, with personal UserSettings storage.
- Official-template VPM installation website, verified package index and automated release workflows.
- MIT or Apache-2.0 license choice, retaining MIT notices for original settings style and header/tab-layout portions.
